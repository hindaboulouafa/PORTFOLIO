01 / about

Infrastructure is more
interesting when you see the whole system.

My professional background started in IT support, but my work has increasingly moved toward systems administration, networking, virtualization, cloud and infrastructure.

I work across both Linux and Windows environments, dealing with users, servers, networks, cloud services, web infrastructure and troubleshooting.

Networking is one of the areas I enjoy most. I like understanding what happens between systems — from DNS and connectivity to the application layer — and tracing problems instead of simply treating symptoms.

I'm currently developing toward Cloud Infrastructure and DevOps, with a focus on automation, containers, monitoring, infrastructure security and reliable deployments.
